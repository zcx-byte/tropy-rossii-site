# Тропы России

Проект сайта для поиска, просмотра и планирования пеших маршрутов. 

### ИИ-чатбот (GigaChat)
Бот работает через GigaChat API. 
Модель по умолчанию — `GigaChat-2`.

Ключ берётся в личном кабинете GigaChat.

## Структура
- HTML-файлы в корне — страницы сайта.
- `css/` — стили.
- `js/` — логика.
- `server.js` — локальный сервер + прокси к GigaChat.
- `admin.html` — панель администратора.
