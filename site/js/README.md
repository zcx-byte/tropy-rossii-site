# JavaScript проекта

- `app.js` — каталог маршрутов на главной странице: фильтры, карточки, загрузка и отображение данных.
- `auth.js` — авторизация, избранное, личный план и общие действия с маршрутами.
- `account.js` — содержимое страницы профиля и переключение вкладок.
- `route.js` — подробная страница маршрута и её интерактивные блоки.
- `map-data.js` — резервные настройки и координаты карт маршрутов.
- `trail-assistant.js` — чат-помощник, история и обработка сообщений.

Скрипты подключаются из HTML через `defer`, поэтому сохраняется порядок загрузки и обработка после разбора HTML.
